ClipForge

A personal pipeline for turning licensed YouTube footage into vertical, captioned clips.

What it does

ClipForge runs on its owner's own computer. It watches a list of YouTube channels that publish under Creative Commons, downloads candidate videos, cuts the strongest moments into vertical clips with burned-in captions, and uploads those clips to the owner's own YouTube channel on a fixed schedule.

It is a single-user tool. There is no sign-up, no hosted service, no other users, and nothing to download from this page.

How it uses Google APIs

  • It requests the youtube.upload scope to publish clips to the owner's own channel.
  • It reads the owner's own channel data (channel identity, video list and status) to schedule and verify uploads.
  • It does not read, request or store data belonging to any other Google user.
  • OAuth tokens are stored in a local file on the owner's computer and are never transmitted anywhere except to Google's own API endpoints.

Privacy policy

Last updated 21 November 2026.

ClipForge is operated by one person, for one YouTube channel. This policy describes everything it does with data.

  • What it accesses. Google account identifiers returned by the OAuth flow, the owner's channel name and ID, and metadata of the videos on that channel (titles, descriptions, privacy status, publish times). Uploaded video files and their metadata are handled the same way.
  • Where it is stored. A SQLite database and a media folder on the owner's own computer (C:\ClipForge\data). Nothing is stored on a server or in a cloud account.
  • Who it is shared with. Nobody. Clip data is sent only to the YouTube Data API to perform the uploads the owner requested. There is no analytics, no advertising, no third-party service, and no sale or transfer of data to anyone.
  • How long it is kept. Locally until the owner deletes it. Deleting a clip in the dashboard removes its file and its database record; deleting the data folder removes everything.
  • Revoking access. Access can be revoked at any time at myaccount.google.com/permissions. Doing so stops all API access immediately.

ClipForge's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
